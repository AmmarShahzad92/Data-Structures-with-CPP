# Data Structures with C++

This repository offers a comprehensive collection of C++ code dedicated to implementing and practicing fundamental data structures. It leverages the power of the Standard Template Library (STL) and also includes custom implementations to provide a thorough understanding of how these structures work.

## Modules

The repository is organized into the following modules, each focusing on a specific data structure:

*   **Vectors**: Dynamic arrays that can grow and shrink in size.
*   **Lists**: Doubly-linked lists providing efficient insertion and deletion.
*   **Deques**: Double-ended queues supporting fast insertions and deletions at both ends.
*   **Stacks**: LIFO (Last-In, First-Out) structures.
*   **Queues**: FIFO (First-In, First-Out) structures.
*   **Maps**: Associative containers that store elements in a mapped fashion (key-value pairs).
*   **Sets**: Containers that store unique elements in a sorted order.

## Practice Section

A dedicated `Practice` folder is included to reinforce learning. It contains various exercises and problems designed to improve algorithmic thinking and problem-solving skills using the data structures covered in this repository.
